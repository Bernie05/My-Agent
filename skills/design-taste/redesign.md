# Redesign protocol

From taste-skill (MIT, Leonxlnx), condensed.

## 1. Detect the mode first
- **Greenfield:** no site, or a full visual overhaul approved.
- **Preserve:** modernize without breaking the brand. Audit, extract the brand tokens, evolve.
- **Overhaul:** new visual language on existing content. New visuals; content and information architecture kept.

If unclear, ask once: "Should this redesign keep the current brand, or start visually from scratch?"

## 2. Audit before touching
Brand tokens (colors, type, logo, radii) · page tree and key conversion paths · which content does work and which is filler · signature patterns to keep · AI tells and broken layouts to retire · the current site's dial reading (your starting point) · SEO baseline (ranking pages, titles, structured data, OG cards).

## 3. Levers, in order (stop when the brief is met)
1. Typography refresh (the biggest lift for the least risk)
2. Spacing and rhythm
3. Color recalibration (unify neutrals, keep the brand accent)
4. Motion layer (`motion-design`)
5. Recompose the hero and key sections
6. Replace whole blocks, only when unsalvageable

Sound IA, content and SEO → targeted evolution (levers 1-4). Structural debt (broken IA, no system, broken mobile) → full redesign that preserves content. Brand changing → greenfield.

## 4. Never change without explicit approval
URLs and route slugs · primary nav labels · form field names and order (analytics, autofill) · logo or wordmark · legal, consent and cookie copy · analytics event names and section IDs. Don't regress existing accessibility (focus, alt text, keyboard, contrast).
