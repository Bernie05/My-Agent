## Component Library Standards

### Component Checklist

✅ **Visual**

- All variants designed
- All states (default, hover, focus, active, disabled)
- Responsive design
- Dark mode support
- Accessible colors

✅ **Documentation**

- Purpose documented
- Usage examples
- Do's and don'ts
- Figma link
- Code examples

✅ **Accessibility**

- WCAG AA compliant
- Keyboard navigable
- Screen reader friendly
- Focus indicators visible
- Color contrast >= 4.5:1

✅ **Code**

- TypeScript types
- Props documented
- Accessible HTML
- Responsive CSS
- Performance optimized

✅ **Testing**

- Unit tests
- Integration tests
- Accessibility tests
- Visual regression tests
